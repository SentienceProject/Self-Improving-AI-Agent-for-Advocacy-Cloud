# Corpus sources

The original workspace's corpus held these papers as plain text (`.md`, one file per paper, with
`<!-- page N -->` markers). They aren't redistributed here because of copyright. Download the ones you want,
convert them to text, and put them in this folder. Any `.md` or `.txt` files work: the agents grep this folder,
so plain text is all they need.

- Goldstein, "AI Death"
- Finlinson, "Key strategic considerations for taking action on AI welfare"
- Fenwick, "Moral status of digital minds"
- Long et al., "Studying AI Welfare Empirically"
- Long et al., "Taking AI Welfare Seriously"
- Simon, "What is it like to be AlphaGo?"

For animal-welfare work, swap in your own sources. `CLAUDE.md` says "AI-welfare research papers" in the corpus
section; change that line to match.
